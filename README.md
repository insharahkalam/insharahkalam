### 🧠 &nbsp; ThinkBoard

**A distraction-free note-taking playground where thoughts turn into structured, searchable notes.**

Built end-to-end with the **MERN stack** — from schema design to pixel-perfect UI. A full-stack productivity app that lets users capture, organize, and revisit their ideas anywhere, anytime.

**✨ &nbsp; Key Features**
- 🔐 &nbsp; Secure JWT-based authentication flow
- ⚡ &nbsp; Blazing-fast CRUD with optimistic UI updates
- 🎨 &nbsp; Fully responsive interface (mobile → desktop)
- 🌐 &nbsp; RESTful API architecture with clean separation
- 💾 &nbsp; MongoDB persistence with Mongoose schemas
- 🚀 &nbsp; Deployed on Vercel & Render for global reach

**🧪 &nbsp; Stack**
`React` `Node.js` `Express` `MongoDB` `Tailwind CSS` `DaisyUI`
